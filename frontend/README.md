# فرانت‌اند Angular — نگهداری و تعمیرات خودرویی

رابط کاربری سازمانی ساده و تمیز که به API پایتون وصل می‌شود.
همه ثبت‌ها با چت انجام می‌شود؛ هیچ فرم ورودی نیست.
گریدها فقط رکوردها را نشان می‌دهند.

## اجرا

```bash
# اول بک‌اند را در یک ترمینال جدا اجرا کن:
# python -m uvicorn api:app --reload --port 8000

npm install
npm start
# باز کن: http://localhost:4200
```

## نما‌ها

- **چت:** گفتگو با چت‌بات، نوار توکن، نشان ابزار
- **گرید:** جدول رکوردهای هر ماژول؛ کلیک روی ردیف جزئیات را نشان می‌دهد
- **نمودار ماژول‌ها:** مراحل workflow به ترتیب با تعداد رکورد؛ کلیک روی هر مرحله گرید همان ماژول را باز می‌کند

## فایل‌های مهم

- `src/app/app.ts` — منطق نما‌ها (چت، گرید، نمودار)، پیام‌ها و توکن‌ها
- `src/app/app.html` / `app.css` — ظاهر صفحه
- `src/app/api.service.ts` — صدا زدن API پایتون (`/api/chat` ، `/api/modules` ، `/api/records/...`)
- `src/app/app.config.ts` — فعال کردن HttpClient

فرانت‌اند هیچ کلیدی ندارد؛ همه کلیدها فقط در `.env` بک‌اند پایتون است.
